# text-2077 - Product Context

## Product
Cyberpunk text visualizer - A web application that transforms user text input into animated particle effects with glitch/cyberpunk aesthetics.

## Users
- Cyberpunk enthusiasts
- Digital artists
- Creative developers
- Fans of retro-futuristic aesthetics

## Brand Personality
- **Tone**: Edgy, futuristic, dystopian, glitchy
- **Keywords**: Neon, terminal, corrupted data, neural networks, 2077
- **Anti-references**: Clean corporate UI, flat design, material design, default blue/red SaaS

## Visual Strategy
- **Color palette**: Deep blacks (#030303) with neon accents (magenta #ff0080, cyan #00ffff, yellow #ffff00)
- **Typography**: Monospace terminal fonts + elegant serif for contrast
- **Effects**: Scanlines, noise, chromatic aberration, glitch artifacts
- **Vibe**: 1990s cyberpunk meets modern web

## Design Decisions
- Terminal-inspired input with blinking cursors
- RGB split effects on text
- Particle systems that form text shapes
- CRT screen effects (scanlines, vignette, noise)
- Color: Full palette - neon colors are core to the brand
- Theme: Dark only - cyberpunk demands darkness

## Tech Stack
- React 19 + TypeScript
- Vite
- Framer Motion for animations
- Canvas API for particle rendering
- React Compiler enabled
